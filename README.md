## `Dev:\ > about`

I like software that has to work outside the editor.

That means I care about the full path: application architecture, APIs, data, authentication, deployment, infrastructure, observability, recovery, and the automation that ties everything together.

My main development environment is **C# / .NET**, with **PowerShell** doing a lot of the glue work around it. I also spend a lot of time experimenting with self-hosted infrastructure, local AI, coding agents, and MCP-based tooling.

I study **Computer Science Engineering (BProf)** at **Óbuda University — John von Neumann Faculty of Informatics**.
